# 🐶 Desktop Buddy

A cute little desktop companion built with HTML, CSS, JavaScript and Electron.

## Features

- Transparent window
- Always-on-top
- Frameless
- Doesn't replace your desktop
- Autonomous wandering
- Walking animation
- Sitting
- Sleeping
- Mouse interaction
- Cute reactions
- Windows desktop application

## Requirements

Install Node.js first.
